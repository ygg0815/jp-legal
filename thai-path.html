繁體中文

泰語小徑的學習進度、收藏及自訂詞條儲存在你的裝置上。本版本沒有帳號、廣告、分析或追蹤 SDK，也不將這些資料傳送給開發者。

麥克風僅在你選擇錄音並允許權限後使用。練習錄音在裝置上供你播放比較，離開錄音頁時刪除，不包含在學習備份。內建音檔於裝置上播放。使用 Apple 系統朗讀時，部分聲音可能需要先下載。

通知僅在你允許後啟用，可隨時關閉。你可匯出 JSON 備份、匯入備份或清除學習記錄。匯出檔案可能包含自訂內容，請自行保管；匯入會取代目前學習記錄。

English

Thai Path stores progress, bookmarks and custom entries on your device. This version has no account, advertising, analytics or tracking SDK and does not send this data to the developer.

The microphone is used only when you choose to record and grant permission. Practice recordings stay on your device, are removed when leaving the recording screen, and are not included in learning backups. Bundled audio plays on the device. When using Apple system speech, some voices may need downloading.

Optional local notifications require permission and can be disabled. You can export a JSON backup, import a backup or reset progress. Exported files may contain your own content; keep them securely. Import replaces existing learning records.

マイクは録音を選び、許可した場合のみ使用します。録音は端末内で再生でき、録音画面を閉じると削除され、バックアップには含まれません。内蔵音声は端末で再生します。Appleのシステム音声を使用する場合、音声のダウンロードが必要なことがあります。

任意の通知は許可後に有効となり、停止できます。JSONバックアップの書き出し・読み込みや記録の削除が可能です。書き出したファイルは安全に管理してください。読み込みは現在の記録を置き換えます。
